# Code of Conduct

## Our standards

We want this project to be a welcoming, respectful place to contribute. Examples of behavior that
supports that goal include:

- Using inclusive and considerate language.
- Respecting different viewpoints and levels of experience.
- Giving specific, constructive feedback.
- Focusing discussion on what is best for users and the project.
- Taking responsibility for mistakes and correcting them.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, threats,
deliberate disruption, publishing another person's private information, or other conduct that a
reasonable person would consider inappropriate in a professional community.

## Scope

This Code of Conduct applies in repository discussions, issues, pull requests, and other project
spaces. It also applies when someone is publicly representing the project.

## Enforcement

Project maintainers may edit or remove contributions that violate these standards and may temporarily
or permanently restrict participation when necessary. Enforcement decisions should be fair,
proportionate, and focused on maintaining a safe community.

Report conduct concerns to the repository maintainers through GitHub's repository reporting tools.
If the report contains sensitive information, do not post it publicly; request a private channel
without including the details. Maintainers will respect the privacy and safety of reporters as far as
possible.

This document is a concise adaptation of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
