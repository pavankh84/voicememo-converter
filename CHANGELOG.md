# Changelog

## [1.0.0] - 2026-10-20

First stable release of Voice Memo Converter:

- Convert voice recordings to MP3 locally, with conversion starting automatically after file selection or drop.
- Preserve recording dates in MP3 ID3 metadata.
- Optionally trim silence from the beginning and end of recordings.
- Create local multilingual Whisper transcripts with explicit language selection.
- Install the offline-capable PWA app shell.
- Keep recordings private with a browser-only, no-upload architecture.
- Contribute using the included setup guide, code of conduct, security policy, and issue templates.
